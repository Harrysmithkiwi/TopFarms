## The three rules that keep this true

**1. One fact, one home.** A number repeated in four places is a number wrong in three. The
readiness score, the brand hexes and the current state each have exactly one owner above.

**2. Never summarise canon.** A summary of a canon is a copy of a canon, and copies rot. On
2026-08-25 `marketing/BRAND.md` was found wrong on *every line* of its quick-recall list, and
three other documents were asserting colours retired in June. Where a summary is genuinely
useful — marketing work happens outside the app — it must say out loud that it is a pointer
and that the canon wins.

**3. Prefer generated over written.** `docs/design/contrast.md` is regenerated by
`scripts/contrast.mjs` and cannot drift without the gate going red. It is the only
self-verifying document here. **Every document a gate does not check is a document that will
eventually be wrong** — which is the same lesson the thirteen design-sync commits kept
teaching, five separate times, in five separate gates.

# Spent prompts

One-shot instructions, written to be pasted into a session once. Consumed; kept for the
reasoning inside them, which is often the only record of why a slice was scoped a certain way.

**A prompt is a message, not a reference.** These read like current instructions because they
are phrased as instructions — that is exactly why they are filed under `_spent/` rather than
sitting in `.planning/` looking live. Before acting on anything in here, check `.planning/NOW.md`.

Live prompts — work scoped but not yet done — stay one level up in `.planning/prompts/`.
